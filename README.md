# Juego 21 🎮

A simple Game of Logic.
Juego del 21 para Flipper Zero. Cuenta del 1 al 21 — quien diga 21 pierde. 

<img width="512" height="256" alt="Screenshot-20260327-235215" src="https://github.com/user-attachments/assets/76d509a3-1f8a-40eb-b169-1871dd05c9c7" />


## Cómo jugar

- Di 1, 2 o 3 números por turno
- Turno alterno entre tú y el Flipper
- Quien diga 21 pierde
- **Truco:** quien llegue a 4, 8, 12, 16 y 20 gana siempre

## Controles

| Botón | Acción |
|---|---|
| `←` `→` | Cambiar cantidad de números |
| `OK` | Confirmar |
| `Back` | Salir |

## Instalación

Descarga `juego_21.fap` de [Releases](../../releases) y cópialo a `/apps/Games/` en tu SD.

## Compilar
```bash
ufbt
```
